Spring AI + Ollama

Lokal LLM ilə 4 nümunə: streaming chat, structured output, tool calling və RAG. Cavab gəlmirsə, Ollama-nın işlədiyini yoxlayın (README).

1. Streaming chat + yaddaş

GET /api/chat/stream. Cavab token-token SSE ilə gəlir. Eyni conversationId ilə model əvvəlki mesajları xatırlayır (məs. "Adım Aynurdur", sonra "Adım nə idi?").

2. Structured output

POST /api/extract. Sərbəst mətndən Java record-u (OrderDraft) çıxarılır.


  


  

    
3. Tool calling

    
POST /api/tools/ask. Model lazım olanda Java metodlarını (getOrder, cancelOrder) özü çağırır. Aşağıda hansı tool-un hansı arqumentlə çağırıldığı görünür.

    

      
      
    

    

  


  

    
4. RAG: bu repodakı kitabdan cavab

    
GET /api/rag/stream. docs/ fəsilləri start-da vektor bazasına yazılır. Sual gələndə ən uyğun 4 parça tapılır və model yalnız onlara əsasən cavab verir.
