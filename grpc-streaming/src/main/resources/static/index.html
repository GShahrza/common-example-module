gRPC: dörd çağırış növü

Brauzer native gRPC danışa bilmir, ona görə bu səhifə gateway vasitəsilə işləyir:

Brauzer ──HTTP (JSON / NDJSON / SSE)──► Gateway :8082 ──gRPC (HTTP/2, protobuf)──► OrderService :9090

1. Unary: bir sorğu → bir cavab

rpc GetOrder(GetOrderRequest) returns (Order). Adi REST çağırışına bənzəyir. 9999999 yazıb gRPC NOT_FOUND statusunun HTTP 404-ə çevrildiyinə baxın.

2. Server streaming: bir sorğu → çox cavab

rpc ListOrders(ListOrdersRequest) returns (stream Order). Gateway hər gələn mesajı NDJSON sətri kimi ötürür. "Dayandır" gRPC çağırışını serverdə də ləğv edir.

3. Client streaming: çox sorğu → bir cavab

rpc UploadOrders(stream Order) returns (UploadSummary). Gateway N sifarişi tək-tək göndərir, server yalnız sonda bir cavab qaytarır.

4. Bidirectional streaming: hər iki tərəf istədiyi vaxt göndərir

rpc Chat(stream ChatRequest) returns (stream ChatResponse). Suallar 300 ms fasilə ilə göndərilir, cavablar isə eyni gRPC çağırışında paralel gəlir.
