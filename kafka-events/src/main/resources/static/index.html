Event-driven: Kafka ilə sifariş saga-sı

Sifariş → outbox → orders topic → ödəniş (idempotent, retry, DLT) → outbox → payments topic → sifariş statusu. Cədvəllər hər saniyə yenilənir.

Sifariş ver

≤ 1000: ödəniş keçir (CONFIRMED). > 1000: rədd (CANCELLED, kompensasiya). 13: ödəniş gateway-i "işləmir" → 2 retry → DLT → CANCELLED.

Sifarişlər

"Təkrar göndər" eyni event-i (eyni eventId) Kafka-ya bir də göndərir. Ödəniş ikinci dəfə çıxılmır.
