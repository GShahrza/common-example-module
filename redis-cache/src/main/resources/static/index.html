Redis ilə keşləmə

"Baza" hər sorğuda 300 ms gözləyir. Birinci oxuma bazadan (db), sonrakılar Redis-dən (cache) gəlir. Terminalda docker exec -it redis redis-cli monitor ilə Redis əmrlərini canlı izləyin.

1. Məhsul: @Cacheable, @CachePut, @CacheEvict


  


  

    
2. TTL: valyuta məzənnələri (10 saniyə)

    
Xarici API 500 ms çəkir. 10 saniyə ərzində məzənnə keşdən gəlir, sonra yenidən alınır.

    

    

  


  

    
3. Cache stampede: @Cacheable(sync = true)

    
Keş silinir və hesabat (1 saniyəlik hesablama) N paralel sorğu ilə eyni anda istənilir. Yalnız biri hesablayır, qalanları onun nəticəsini gözləyir.
