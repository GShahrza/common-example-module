Spring MVC: cavabı hissə-hissə göndərmək

Hər nümunədə server cavabı bitirməmiş brauzer məlumatı göstərməyə başlayır. Network tab-da (DevTools) cavabın necə gəldiyinə baxın.

1. Chat cavabı: SSE (SseEmitter)

ChatGPT kimi: mətn söz-söz gəlir. Brauzer tərəfdə EventSource.

2. Uzun işin gedişatı: SSE + yenidən qoşulma

Hər hadisənin id-si var. Əlaqə kəsilib bərpa olunanda server qaldığı yerdən davam edir (Last-Event-ID).

3. Böyük siyahı: NDJSON (ResponseBodyEmitter) və adi JSON

Eyni məlumat iki cür. NDJSON-da hər sətir ayrıca JSON-dur və gələn kimi göstərilir; adi JSON-da hər şey sonda bir dəfəyə gəlir. "İlk sətir" vaxtını müqayisə edin.

4. Fayl yükləmə: CSV (StreamingResponseBody)

100 000 sətir. Server faylı yaddaşda yığmır, yükləmə dərhal başlayır.
