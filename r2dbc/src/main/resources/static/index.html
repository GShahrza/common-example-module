R2DBC: bazaya bloklamadan

WebFlux + PostgreSQL. Cədvəldə 100 000 sifariş var. Eyni 200 ms-lik sorğu (pg_sleep(0.2)) üç üsulla; bazadan brauzerə axın; reaktiv tranzaksiya.

1. N paralel sorğu: R2DBC, event loop-da JDBC, ayrı pool-da JDBC

Server-in 4 event-loop thread-i var; R2DBC və JDBC pool-larında 20 bağlantı var.

2. Bazadan brauzerə axın (NDJSON)

Sətirlər PostgreSQL-dən 250-lik hissələrlə, oxunduqca gəlir: ilk sətir bütün sorğu bitməmiş görünür. "1000 sətirdən sonra dayandır" bağlantını kəsir: server bunu cancel kimi alır və bazadan oxumağı dayandırır (yolda olan, TCP buferlərindəki sətirlər istisna).


  


  

    
3. Reaktiv tranzaksiya: sifariş + stok

    
Stok azalır və sifariş yazılır, ya da heç biri. "Noutbuk"un stoku 5-dir.
