Onlayn

    STOMP frame-ləri

    STOMP sadə mətn protokoludur: komanda, header-lər, boş sətir, body və \0. Aşağıda bu səhifənin göndərdiyi (→) və aldığı (←) frame-lər görünür.

    Müqayisə: STOMP-suz, xam WebSocket

    /ws/echo yalnız mətn frame-ləri qəbul edir və qaytarır. Otaq, istifadəçi, marşrutlaşdırma yoxdur; bunları özünüz icad etməli olardınız.
